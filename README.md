## Affects Gameplay 기준

| Type | Description |
|---|---|
| Y (Yes) | 게임 규칙, 밸런스, 서버 상태, 월드 데이터, 동기화 결과, 플레이어 간 공정성에 영향을 줍니다. |
| N (No) | 실제 게임 결과를 바꾸지 않습니다. 보통 클라이언트 전용 UI, 시각 효과, 로그, 문서, 도구성 기능입니다. |
| C (Configurable) | 설정값, 서버 옵션, 활성화된 기능에 따라 게임 플레이에 영향을 줄 수도 있고 아닐 수도 있습니다. |
| U (Unknown) | 멀티플레이 영향 여부를 아직 충분히 확인하지 않았습니다. |
