## Status Guide

| Status | Meaning |
|---|---|
| Planning | 아이디어 구상 단계 |
| Prototype | 실험 구현 단계 |
| In Development | 개발 진행 중 |
| Playable | 기본 사용 가능 |
| Maintenance | 유지보수 중 |
| Paused | 보류 중 |
| Archived | 개발 종료 또는 보관 |

## Affects Gameplay 기준

| Type | Description |
|---|---|
| Y (Yes) | 게임 규칙, 밸런스, 서버 상태, 월드 데이터, 동기화 결과, 플레이어 간 공정성에 영향을 줍니다. <br> 멀티플레이에서 모드 사용시 모든 플레이어가 동일한 모드를 사용해야 합니다. |
| N (No) | 실제 게임 결과를 바꾸지 않습니다. 클라이언트 전용 UI, 시각 효과, 로그, 문서, 도구성 기능 등 |
| C (Configurable) | 설정값, 서버 옵션, 활성화된 기능에 따라 영향을 줄 수도 있고 아닐 수도 있습니다. |
| U (Unknown) | 멀티플레이 영향 여부를 아직 충분히 확인하지 않았습니다. |
